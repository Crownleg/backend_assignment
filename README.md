## Description
a RESTful API built using Node.js, Express, and MongoDB implementing full CRUD operations.

## Technologies
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Render

## Environment Setup
Create a `.env` file with:
PORT=5000
MONGO_URI=your_mongodb_connection_string

## API Endpoints
POST /api/users  
GET /api/users  
GET /api/users/:id  
PUT /api/users/:id  
DELETE /api/users/:id  

## Deployment
Render URL: https://your-app.onrender.com

## Run Locally
npm install  
npm run dev
